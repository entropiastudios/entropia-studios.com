Falta un paso de configuración

El panel ya está publicado, pero todavía no tiene las contraseñas ni el permiso para guardar.

  1. Entrá a Cloudflare → Workers & Pages → entropia-studios → Settings → Variables and Secrets.
  2. Agregá cada uno de estos, del tipo Secret:
    • Guardá y recargá esta página.

    ADMIN_PASSWORD_… es la contraseña de cada persona, la que elijas. GITHUB_TOKEN es el permiso de GitHub sobre el repositorio de la web (Contents: read and write).
